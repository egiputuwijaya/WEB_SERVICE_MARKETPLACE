Panduan Penggunaan Mockup Vektor SVG di Figma

Ikuti langkah mudah berikut untuk melampirkan rancangan visual ke laporan tugas kuliah.

1 Unduh File

Klik tombol Download SVG pada salah satu atau seluruh kartu mockup di atas.

2 Buka Figma

Buka kanvas kerja di Figma desktop app atau browser di figma.com.

3 Drag & Drop

Tarik file .svg dari folder Downloads komputer Anda langsung ke tengah kanvas Figma.

4 Edit & Ekspor

Ubah teks JSON bila diperlukan, lalu pilih frame dan ekspor ke format PNG @2x untuk laporan Word.
